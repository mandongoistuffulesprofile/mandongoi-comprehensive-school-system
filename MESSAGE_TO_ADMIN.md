# Message to School Admin — M-Pesa Go-Live

---

Copy and send this via WhatsApp/Email:

---

**Subject:** M-Pesa Online Fee Payment — Information Needed

Hi [Admin Name],

I'm ready to connect the school's M-Pesa Paybill to the new school management system so parents can pay fees directly via M-Pesa and payments match automatically to student accounts.

To do this, I need to submit a Go-Live request on the Safaricom Developer Portal using your existing Paybill. Please provide the following:

**1. Your M-Pesa Paybill Number**
The 5-6 digit number parents currently send fees to (e.g., 123456).

**2. M-Pesa Business Admin Username**
The username you use to log in to the Safaricom M-Pesa portal at safaricom.co.ke/business. This is required by Safaricom during the Go-Live application.

**3. Organization Name**
The official school name as registered with Safaricom for the Paybill (e.g., "Mandongoi Comprehensive School").

**4. M-Pesa Registered Phone Number**
The phone number associated with the Paybill account (the one Safaricom uses for official communication).

---

**What happens next:**
1. I submit the Go-Live request via the Safaricom Developer Portal using the above details
2. Safaricom reviews and approves (usually 1-3 days)
3. I receive production API credentials and configure the system
4. We test with a small payment
5. System goes live — parents pay via Paybill, payments auto-match to student invoices

**No cost involved.** This does not change how parents pay — they continue using the same Paybill number. The only difference is the system will now automatically detect the payment and update the student's fee record.
